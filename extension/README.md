# 拾光导航 · 一键收藏（浏览器扩展）

把任意网页收藏到你的拾光导航站：点工具栏图标 / 按 `Alt+S` / 右键菜单 → 弹出确认窗（自动读取全部分类、AI 推荐分类与简介）→ 确认后入库。

## 安装（开发者模式加载，免上架）

1. 打开扩展管理页：
   - Chrome / Comet：地址栏输入 `chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角（Edge 在左侧栏）的 **「开发者模式」** 开关
3. 点 **「加载已解压的扩展程序」**，选择本项目的 `extension` 文件夹（就是本目录）
4. 建议点浏览器右上角拼图图标，把「拾光导航」**固定**到工具栏

首次使用：扩展图标右键 → **选项** → 确认站点地址 → 粘贴连接码（导航站「设置 → 数据 → 浏览器扩展」生成）→ 保存 → 「测试连接」。

## 换浏览器 / 重装系统怎么办

- 扩展源码随项目一起存在 **GitHub 私有仓库**（`extension/` 目录），不会丢
- 新环境：`git clone` 仓库（或在 GitHub 页面 Code → Download ZIP 解压）→ 重复上面安装步骤 → 重新粘贴一次连接码即可
- 连接码本身长期有效（按你选的时长），不用重新生成；除非你点了「重新生成」（旧码会立即失效）

## 打包 zip

```bash
npm run ext:pack   # 生成 shiguang-nav-extension.zip（商店上传用同一份）
```

## 上架 Chrome 应用商店（可选）

可以上架，流程与费用：

1. 注册 [Chrome Web Store 开发者账号](https://chrome.google.com/webstore/devconsole)（需 Google 账号 + **一次性 $5** 注册费）
2. `npm run ext:pack` 生成 zip → 开发者控制台「新增项」上传
3. 填写商品信息（下方文案可直接粘贴）、上传截图、填写隐私说明：
   - 单一用途说明：把当前网页一键收藏到用户自建的拾光导航站
   - 权限说明：`activeTab`（读取当前标签页标题/地址）、`storage`（本地保存站点地址与连接码）、`notifications`（收藏结果提示）、`contextMenus`（右键菜单）；`optional_host_permissions` 在用户于选项中配置自己站点地址时申请对应域名访问权
4. 可见性建议选 **「不公开（unlisted）」**：只有拿到链接的人能搜到/安装——这是个人工具，公开上架没有意义
5. 提交审核（通常几小时到几天）

**商店文案（可直接粘贴）**：

> 标题：拾光导航 · 一键收藏
> 简述：把当前网页一键收藏到你的拾光导航站。弹出确认窗：AI 推荐分类与简介，可从全部分类中自选，确认后入库。
> 说明：需要自部署的拾光导航站（https://github.com/diaoyudao100/shiguang-nav）并在站点「设置 → 数据 → 浏览器扩展」生成连接码。本扩展不会上传数据到任何第三方：网址与标题仅发送给你自己配置的导航站地址。

注意：无论从商店安装还是开发者模式加载，**连接码都要自己粘贴一次**——商店不提供"自动关联你的账号"这种能力。
